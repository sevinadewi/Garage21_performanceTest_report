Cara membaca hasil

  • Average: rata-rata waktu respons seluruh sampel pada endpoint.
  • Median: nilai tengah waktu respons setelah seluruh sampel diurutkan.
  • 90% / 95% / 99% Line: persentil. Contoh 90% Line = 500 ms berarti sekitar 90% sampel selesai dalam 500 ms atau kurang; sekitar 10% lebih lama.
  • Min / Max: waktu respons tercepat dan terlambat yang tercatat.
  • Error %: persentase sampel yang gagal menurut JMeter. 0% berarti tidak ada error yang tercatat.
  • Throughput: jumlah request yang diproses per detik selama pengujian (request/second).
  • Received / Sent (KB/s): kecepatan data yang diterima dari server dan dikirim ke server per detik.
  • Samples: jumlah request yang tercatat untuk endpoint tersebut.

Catatan: Data ini berisi satu sampel untuk setiap endpoint. Karena itu, Average, Median, 90%, 95%, dan 99% bernilai sama pada setiap baris. Persentil belum bermakna untuk menilai sebaran performa sampai pengujian diulang dengan lebih banyak sampel. Ini bukan bukti bahwa aplikasi mampu menangani banyak pengguna sekaligus. Hasil lokal juga dapat berbeda dari server produksi.
